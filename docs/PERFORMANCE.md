# Compute-Unit Performance

> Auto-generated by `scripts/measure-cu.sh`. Re-run after meaningful changes
> to instruction bodies. Source: `.anchor/program-logs/*.log` "consumed" lines.
>
> Solana default CU budget per instruction = 200,000. Treat >100,000 as a
> yellow flag and >150,000 as red.

## How to (re-)generate

```bash
pnpm cu:measure
```

That runs the full integration test suite (which spawns its own validator),
parses every `consumed N of M compute units` line out of the per-program
logs, and aggregates min / mean / p95 / max per instruction into this file.

If you only want to re-aggregate without re-running tests (e.g. you just
called `pnpm test` manually):

```bash
pnpm cu:measure -- --skip-test
```

## How the validator works for ad-hoc inspection

```bash
pnpm validator:up           # background; logs go to .anchor/validator.log
pnpm test                   # or `anchor test --skip-local-validator`
pnpm validator:down
```
